# 随手账｜跟夏末做产品 · 第一集

运行：Windows上解压整个目录，右键index.html，选择Microsoft Edge打开。无需安装依赖。
这是个人浏览器内的教学MVP，数据放在localStorage，不会上传到账户或云端。
请使用同一浏览器资料并保留文件位置；不同浏览器对本地文件存储的处理可能不同。移动文件、清除网站数据或换浏览器可能看不到原记录。本版只适合虚构数据教学试用，不作为重要账目的唯一副本。

验收：
1. 金额32，日期选今天，餐饮，备注午饭；保存后1笔，合计32。
2. 刷新同一文件，原记录仍在。
3. 修改该记录为23；明细、月合计、分类金额为23，仍为1笔。
4. 输入0；保存失败且原数据不变。

结构：HTML定义页面，CSS定义样式，JavaScript处理浏览器交互和本地存储。后端、服务端数据库、账号、跨设备同步和订阅都未实现。
